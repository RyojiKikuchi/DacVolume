# DacVolume

PIC16F13113 を使ったボリューム制御ファームウェアです。  
可変抵抗（ボリューム）の位置を ADC で読み取り、DAC 出力に変換します。  

---

## ピンアサイン

| ピン | 機能          | 説明                        |
|------|---------------|-----------------------------|
| RA0  | DAC1OUT1      | DAC アナログ出力             |
| RA1  | VREF+         | DAC/ADC 基準電圧入力         |
| RA2  | LED           | 動作表示 LED                 |
| RA3  | MCLR          | リセット                    |
| RA4  | ADJUST        | 校正ボタン（内部プルアップ）  |
| RA5  | ANA5 (ADC IN) | ボリューム電圧入力           |

---

## 機能

### 通常動作

- Timer0 割り込み（2ms 周期）で ADC を定期的に実行します。
- ADC 結果（10bit: 0〜1023）をキャリブレーション値に基づいて DAC 出力値（8bit: 0〜255）に変換し、`DAC1` へ出力します。
- ADC 値の変動が閾値（`ADC_NOISE_THRESHOLD = 3`）を超えた場合、LED を 500ms 点灯します。
- 電源投入時はフェードイン処理（4ms/ステップ）で DAC 出力を徐々に立ち上げます。

### DAC 出力範囲（デフォルト値）

| パラメータ    | 値      | 備考            |
|---------------|---------|-----------------|
| DAC 最小値    | 47      | 18.43% (8bit換算) |
| DAC 最大値    | 172     | 67.45% (8bit換算) |
| 調整範囲      | ±5      | 最小・最大それぞれ |

### 校正値の保存

校正値は PIC16F13113 の SAF（Storage Area Flash）に保存されます。

| アドレス       | 内容               |
|----------------|--------------------|
| 0x07E0         | ADC 最小値          |
| 0x07E1         | ADC 中央値          |
| 0x07E2         | ADC 最大値          |
| 0x07E3         | DAC 最小値          |
| 0x07E4         | DAC 最大値          |

起動時に SAF から校正値を読み込みます。  
- 校正値が有効範囲内の場合：LED 点灯（1800ms）  
- 校正値が無効な場合：LED 点滅（1800ms）、デフォルト値を使用

---

## 校正モード（ADJUST）

RA4（ADJUST）ボタンを **1秒以上** 押し続けると校正モードへ移行します。  
校正モードに入ったとき、RA5（ADC 入力）の値によって動作が切り替わります。

| ADC 入力範囲   | 実行内容                     |
|----------------|------------------------------|
| 低（≤ 0x55）   | **DAC 最小値** の調整         |
| 中（0x56〜0xAA）| **ADC キャリブレーション**   |
| 高（≥ 0xAB）   | **DAC 最大値** の調整         |

### ADC キャリブレーション手順

1. **中央値の取得**  
   LED が 0.5秒間隔で点滅します（5秒間）。  
   ボリュームを **中央** に合わせて、LED が点灯（1秒）したら次のフェーズへ。

2. **最大値の取得**  
   LED が 0.5秒間隔で点滅します（5秒間）。  
   ボリュームを **最大** に回して、LED が点灯（1秒）したら次のフェーズへ。

3. **最小値の取得**  
   LED が 0.5秒間隔で点滅します（5秒間）。  
   ボリュームを **最小** に回して取得。

取得した 最小 < 中央 < 最大 の条件が満たされ、かつ差分が 512 以上の場合のみ有効として保存されます。

> **校正値リセット**  
> 校正モード移行後の最初の点滅中（5秒）に ADJUST ボタンを押し続けると、  
> SAF の校正値をクリアしてリセットします。

### DAC 最小値／最大値調整手順

1. 現在の DAC 最小値または最大値が LED の点滅回数で表示されます（桁ごとに表示）。
2. ADCの入力値がそのまま(最小値または最大値)の場合、現在の値を2回表示して校正モードを終了します。
3. 現在値を2回表示している間にADCの入力値が中央値になった場合のみ調整モードへ移行します。
4. 値表示開始時にADC 入力値が低い場合はデクリメント、高い場合はインクリメントします。
5. ADC入力値が中央値のままの状態が 10回続くと校正値を保存しないで校正モードを終了します。
6. ADC入力値が中央値のままADJUST ボタンを一秒間押すと現在の値で確定・保存します。

校正完了後、LED が 2秒間点灯します。

## 開発環境

- **IDE**: MPLAB X IDE
- **コンパイラ**: XC8
- **コード生成**: MPLAB Code Configurator (MCC)
- **対象 MCU**: PIC16F13113

---

## ビルド方法

MPLAB X IDE でプロジェクト（`DacVolume.mc3`）を開き、Build を実行してください。

```
Project > Build Project (F11)
```
